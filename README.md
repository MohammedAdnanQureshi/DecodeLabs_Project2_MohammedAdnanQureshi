# Project 2: Exploratory Data Analysis (EDA) in Excel

## 📌 Overview
This project performs Exploratory Data Analysis (EDA) on the cleaned e-commerce dataset using Microsoft Excel. The analysis focuses on understanding data distributions, identifying trends, calculating descriptive statistics, and summarizing key business insights.

## 🎯 Goal
Analyze the cleaned dataset to understand patterns, trends, and distributions.

## ✅ Analysis Performed
### Descriptive Statistics
- Count
- Mean
- Median
- Minimum
- Maximum

### Trend Analysis (Pivot Tables)
- Most Ordered Products
- Revenue by Product
- Monthly Orders
- Payment Method Usage
- Order Status Distribution
- Referral Source Analysis
- Coupon Code Usage

### Outlier Analysis
- Examined the numerical columns (Quantity, UnitPrice, ItemsInCart, and TotalPrice).
- No significant outliers were identified.

### Key Observations
- Identified the most frequently ordered product.
- Determined the product generating the highest revenue.
- Analyzed payment methods and referral sources.
- Summarized important insights from the dataset.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Functions (COUNT, AVERAGE, MEDIAN, MIN, MAX)
